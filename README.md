# مولّد الأسئلة الذكي V2

مشروع مستقل لإنشاء الأسئلة التعليمية بالذكاء الاصطناعي دون الاعتماد على موقع ذرات.

## الحالة
- واجهة عربية متجاوبة جاهزة.
- اختيار نوع الأسئلة ومستوى الصعوبة والعدد واللغة.
- الواجهة تستدعي `/api/generate`، وسيتم إضافة طبقة الخادم الآمنة للذكاء الاصطناعي لاحقًا بحيث لا يوضع مفتاح API في المتصفح.

## الهدف
توليد أسئلة مع الإجابات والخيارات والتفسير من محتوى الدرس مباشرة، ثم إضافة التصدير والمراجعة والتحرير.
