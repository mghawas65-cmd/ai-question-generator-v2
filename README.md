# محفظة المحاسب

منصة عربية RTL مستقلة لتوليد أسئلة محاسبية تدريبية بالذكاء الاصطناعي، مع بنك أسئلة واختبارات ونتائج ومصادر وجودة قابلة للتتبع.

## النسخة الحالية
- توليد 10–30 سؤالًا من موضوع أو حالة عملية.
- أنواع: اختيار متعدد، صح/خطأ، إجابة قصيرة، حالات، ومسائل/قيود.
- أطر: IFRS/IAS، US GAAP، ISA، SOCPA، AAOIFI، IPSAS، غير ربحي، زكاة، ضرائب، تكاليف، إدارية.
- اختصاصات: دولي، عُمان، السعودية، GCC، الولايات المتحدة.
- تاريخ مرجعي (as-of) لكل مجموعة.
- طبقة مراجعة آلية ثانية + ثقة تحقق + حماية من اختلاق أرقام الفقرات.
- Bloom taxonomy وشرح البدائل الخاطئة.
- Cache مؤقت + rate limiting + منع تكرار.
- بيانات تجريبية أولية.
- بنك أسئلة محلي، مفضلة، بحث وتصفية.
- اختبار بمؤقت ونتائج وتحليل نقاط الضعف.
- طباعة/حفظ PDF عبر محرك الطباعة في المتصفح للحفاظ على العربية RTL.
- وضع داكن وتحسينات للجوال.
- بلاغ خطأ لكل سؤال.
- مصادر رسمية وروابط مرجعية.
- CI تلقائي يفحص syntax ومتطلبات RTL/mobile/quality.

## التشغيل
متغير البيئة المطلوب على Vercel:

```
OPENAI_API_KEY=...
```

اختياري:

```
OPENAI_REVIEW_MODEL=...
```

## ملاحظات مهمة
- المحتوى تدريبي مولّد بالذكاء الاصطناعي، وليس بديلًا عن النص الرسمي أو المشورة المهنية.
- لا تدّعي المنصة اعتمادًا رسميًا من جهات المعايير أو الشهادات المهنية.
- بنك الأسئلة والنتائج حاليًا local-first في المتصفح. مخطط قاعدة البيانات السحابية موجود في `db/schema.sql` لكنه غير مفعّل حتى اختيار مزود مصادقة وقاعدة بيانات.

راجع:
- `ACCOUNTING_QUALITY_SPEC.md`
- `ROADMAP.md`
- `CHANGELOG.md`
